## Updating from v3 to v4

The following changes were made to the Router package between v3 and v4.

### Minimum supported PHP version raised

All Framework packages now require PHP 8.3 or newer.

### Serialization library `jeremeamia/superclosure` has been replaced with `opis/closure`

The library used for serialization of closures, [`jeremeamia/superclosure`](https://github.com/jeremeamia/super_closure), is abandoned and has for this release been replaced with the supported library [`opis/closure`](https://github.com/opis/closure).
